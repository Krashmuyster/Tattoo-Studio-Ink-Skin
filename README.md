# Tattoo-Studio-Ink-Skin

Лендинг для тату-студии — учебный проект, вёрстка с нуля по собственному макету.

🔗 [Живая версия] (https://krashmuyster.github.io/Tattoo-Studio-Ink-Skin/)

## О проекте

Одностраничный адаптивный сайт: hero, о студии, услуги, мастера, отзывы, контакты.
Макет собран самостоятельно в Figma, вёрстка — вручную, без фреймворков и генераторов кода.

## Стек

- HTML5 (семантическая вёрстка, BEM)
- CSS3 (Flexbox, Grid, CSS-переменные, адаптивная вёрстка)
